Como funciona

Uma solução simples
para um problema sério

Nossa plataforma conecta sensores inteligentes instalados nos bueiros de Porto Velho a um painel web acessível para todos os cidadãos.

📡
01

Sensor detecta

Um sensor ultrassônico instalado na tampa do bueiro mede continuamente o nível de acúmulo de lixo e água.

📶
02

Dados transmitidos

As leituras são enviadas via LoRa/NB‑IoT para a nuvem em intervalos regulares, sem intervenção humana.

🗺️
03

Visualização no mapa

Os dados aparecem em tempo real no nosso mapa interativo, com cores indicando o estado de cada bueiro.

🔔
04

Alerta automático

Quando um bueiro atinge nível crítico, um chamado é aberto automaticamente para a Prefeitura de Porto Velho.

Nossa tecnologia

Como coletamos as informações

O coração do sistema é o SIG-C (Sistema Integrado de Gestão de Culverts), um dispositivo desenvolvido pela equipe que é instalado discretamente na tampa dos bueiros.

Fonte: Autores, 2026 — Sistema SIG-C instalado na tampa do bueiro

📦 SIG-C – Dispositivo de Campo
🔋
Bateria LiFePO4

Armazena energia para manter o circuito funcionando à noite ou em dias nublados.

⚡
Gerenciador de Carga

Regula a tensão entre o painel solar, a bateria e os circuitos, evitando sobrecargas.

🧠
MCU Principal (ESP32)

Processa as leituras, filtra ruídos do sinal e decide quando emitir alertas de nível crítico.

📡
Módulo LoRa/NB-IoT + Antena

Envia os dados processados via rádio ou rede celular para o sistema em nuvem.

🔊
Sensor Ultrassônico

Emite pulsos sonoros para baixo para medir a altura do acúmulo de lixo dentro do bueiro.
